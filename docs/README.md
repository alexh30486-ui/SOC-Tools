# GitHub Pages demo

`index.html` is a **synthetic, standalone** demonstration of Spectacle SOC v12. It does not run Python, create live network probes, or connect to Supabase/Redis/Gemma. GitHub Pages hosts static files only.

After pushing the repo, open **Settings → Pages**, choose **Deploy from a branch**, and select `main` and `/docs`. Once deployed, the project URL will normally be `https://alexh30486-ui.github.io/SOC-Tools/`.

For the complete application, run `./run.sh` locally or deploy the backend separately with appropriate authentication and explicit authorization.
