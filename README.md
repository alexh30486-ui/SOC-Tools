# SOC-Tools · Spectacle SOC v12

A security-operations investigation workbench with a React/TypeScript + Tailwind-style UI, a local Python HTTP API, sample log analysis, evidence-first cases, versioned playbooks and a safe Network Diagnostics terminal.

> **Demo/live distinction:** The hosted preview and Linux command previews are synthetic. Browser code cannot open arbitrary ICMP/UDP sockets or run operating-system commands. Authorized live network probes require the authenticated API and explicit server-side allowlists. A trained Gemma model, production Supabase, and Redis connections are **not** included or verified.

## Start locally (macOS/Linux)

Requires Python 3.12+ and Git for publishing. Node.js is optional for editing/recompiling the frontend; a prebuilt web interface ships with the source.

```bash
./run.sh
```

Open **http://localhost:8080**. The starter creates a local API secret and SQLite database, ignored by Git. If you intentionally enable Redis/Supabase, follow [INTEGRATION.md](INTEGRATION.md) and use private server-only environment variables.

To rebuild after editing the UI, install Node.js and TypeScript dependencies per [web/README.md](web/README.md). The repository includes the built `web/index.html` and offline `web/preview-offline.html`.

## Test locally

```bash
(cd api && python3 -m unittest discover -s tests -v)
python3 -m unittest discover -s tests -v
python3 -m unittest discover -s tests/integration -v
```

Browser interaction tests additionally require Playwright + Chromium. Historical test receipts in `release/` are previous checks, not proof that GitHub CI has run on the new repository.

## Publish to GitHub

See **[GITHUB_SETUP.md](GITHUB_SETUP.md)** for an exact macOS walkthrough. Create an **empty** `SOC-Tools` repository (no README, licence, or `.gitignore` generated by GitHub). Then, from this directory, run:

```bash
bash publish-to-github.sh
```

The script refuses to overwrite a nonempty remote branch. It does not require `gh` (GitHub CLI), but Git must be authenticated for the push. For a preview website, publish `main` → `/docs` in GitHub **Settings → Pages**.

## Safety, evidence and attribution

No automatic vulnerability exploitation, shell access, packet capture or system changes are initiated. Diagnostics are restricted and intended only for networks you administer or are authorized to test. Demo output is not authentic forensic evidence. The uploaded LoRA evaluation reports a **NO-GO** task-quality gate; its adapter isn't used to make automated decisions.
